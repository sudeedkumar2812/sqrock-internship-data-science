# Student Performance Prediction

## Project Overview

This project uses machine learning techniques to predict student exam performance based on various student-related factors.

The project includes data preprocessing, exploratory data analysis, feature engineering, model training, evaluation, and prediction.

## Dataset

The project uses the `StudentPerformanceFactors.csv` dataset.

The dataset contains information about factors that may influence student academic performance, including study habits, attendance, parental involvement, access to resources, extracurricular activities, sleep, and other student-related factors.

## Objectives

- Analyze student performance data
- Perform data preprocessing
- Explore relationships between student factors and exam performance
- Perform feature engineering
- Train machine learning models
- Evaluate model performance
- Predict student exam scores

## Project Workflow

1. Data Collection
2. Data Preprocessing
3. Exploratory Data Analysis
4. Feature Engineering
5. Machine Learning Model Training
6. Model Evaluation
7. Student Performance Prediction
8. Model Saving and Verification

## How to Run

1. Open `Student_Performance_Predictor.ipynb` in Jupyter Notebook or JupyterLab.
2. Make sure the required Python libraries are installed.
3. Run the notebook cells from beginning to end.
4. The trained model and preprocessing pipeline are saved as `.pkl` files.

## Model

The project trains and evaluates machine learning models to predict student exam performance.

The best-performing model is selected based on the evaluation results.

## Output

The project produces model evaluation results, visualizations, and student exam score predictions.
